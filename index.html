My name is Hayder Nasser, and I am a Grade 11 student at Ethiopian International School Riyadh. Skills Learned

One of the most exciting new subjects this year was Web Design. I learned how computers function internally, and how websites are built layer by layer using HTML and CSS — combining logic with creativity to design real web pages.

In programming, I explored Python and computer vision, creating an interactive air-drawing project. Though the presentation hit a technical snag, the process of building it taught me persistence, debugging, and problem-solving.
